A single deadpan warning label for a time machine: never strand your great-grandmother in the past, because she adapts faster than you do — and the punchline lands in the last words. The program writes the label to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The label it writes (113 characters, one line, no trailing newline):

> WARNING: Do not strand your great-grandmother in the past. She adapts fast, and now owns your apartment building.

Set `OUTPUT_DIR` to write `entry.txt` somewhere else instead of `/output`.
